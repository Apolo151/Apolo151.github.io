# Backlog

Ideas and deferred work. Nothing here is promised; the owner keeps this file alive.

## Deferred features

- Arabic infrastructure writing as its own stream: version 1 starts in English, and the Arabic interface is in place for when posts exist.
- Newsletter by email on each new post: not important at the start, and it needs a third-party service.
- Public notes library: only notes explicitly marked public are copied, and a secret scan runs first. Deferred to soon after version 1 so the first release stays small.
- Photo on the About page: waiting for a decision on whether to show one.
- Custom domain: the build assumes `apolo151.me`; the DNS and Pages settings step is separate from the code.
- Open-source page refreshed from the GitHub API: version 1 uses a hand-maintained data file, which is simpler and cannot break the build.
- Search (for example a static index): not worth the weight until there are enough posts to search.
- Contact form through a form service: a static site needs a third party for it, so version 1 shows an email link instead.
- Social-share images for posts: link previews use title and description for now.
- A "Now" page that updates from data: version 1 is hand-written.
